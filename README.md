# PATTech-com/.github

Org-wide defaults for every PatTech repo. GitHub uses these files in any repo that has no file
of its own, so keep them here only, not in each repo.

- `.github/pull_request_template.md`: the PR template. CI (`pr-compliance`) checks its headings,
  so change it together with `pr-check.mjs` in `.github-private`.

Public by design: nothing secret belongs here.
